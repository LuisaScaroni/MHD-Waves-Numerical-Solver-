# MHD-Waves-Numerical-Solver
Numerical solvers and mathematical derivation for linear MHD waves in a magneti flux tube using Python.

## Project Description:
The aim is investigating linear Magnetohydrodynamic waves within a magnetic flux tube using a cylindrical coordinate system. Through the ideal MHD model, the project studies the physical transitions between different waves regimes.
